# Rebrand: Electious → Electius

**Date:** 2026-07-12 · **Branch:** `feature/rebrand-electius` (merged to `main`, deleted)

## Why

The `electious.com` domain was taken. The brand is now **Electius** and the domain
**electius.com** (being purchased). This is a name change only — no logic, schema, or
routing behaviour changed.

## Scope (full rebrand, code-side)

11 tracked files, 18 lines. Pure string swaps `Electious → Electius` / `electious → electius`:

| Area | Files |
| --- | --- |
| Visible brand text | `src/app/[locale]/layout.tsx` (tab `title` + `description`), `src/components/dashboard/sidebar-nav.tsx` (sidebar brand + logo alt), `src/app/[locale]/(marketing)/layout.tsx` (header brand + logo alt + `© Electius` footer), `src/app/[locale]/(voter)/layout.tsx` (logo alt) |
| Domain in code comments | `src/proxy.ts`, `src/i18n/routing.ts` (`electious.com → electius.com`) |
| Other comments | `src/app/globals.css`, `prisma/schema.prisma`, `prisma/demo-seed.production.sql` (comment; file still untracked, not committed) |
| Package metadata | `package.json` + `package-lock.json` name → `electius`; `.vscode/settings.json` cSpell word |

## Explicitly NOT changed

- **Live domain URLs** — they live in gitignored env vars `NEXT_PUBLIC_APP_URL` /
  `NEXT_PUBLIC_MARKETING_URL`. **Update these manually** to the `electius.com` host
  (same as the earlier `.hr → .com` rename — env files are never committed).
- **Neon project name `electious`** — off-limits per `CLAUDE.md` guardrails; a project
  rename is a Neon-console action, not a code change, and does not affect connection strings.
- `src/generated/prisma/**` — gitignored; regenerated by `prisma generate` on every build.
- `context/` specs, `documentation/` historical dev docs, root `subdomain-routing-setup.md` —
  left as accurate records of the old name.

## Logo caveat

Logo **alt text** now reads "Electius", but the image files `public/logo/logo-mark.png`
and `logo-mark-white.png` are unchanged. They are small (~30px) icon marks shown beside a
separate text `<span>`, so there is no wordmark to swap. If a mark ever embeds the letters,
replace the asset separately.

## Verification

`npm run build` passes — 25 pages, no TypeScript errors, no route collisions. No functional
surface changed, so build-pass is sufficient (pure text rename).
