# Electius - Your Organization Voting Companion

**Electius** is a web platform for secure electronic voting, built for organizations — universities, unions, companies, and associations. It covers the entire election lifecycle in one place: from preparation and invitations, through voting and results, to long-term archiving — with guarantees of **anonymity**, **integrity**, and **audit documentation**, and no IT knowledge required.

## Why Electius

Organizations today run votes manually (paper, email, forms) or rely on expensive, complex systems. Electius is a deliberately accessible alternative that handles the full process end-to-end — secure, official, and effortless for non-technical administrators.

## How It Works

1. **Prepare** — Create an election through a guided wizard and import the voter list (CSV or manual entry).
2. **Publish** — Every voter receives a personalized email invitation with a unique, expiring voting link.
3. **Vote** — Voters open the ballot from the link. Mobile-optimized: 5 screens, under 2 minutes, no account or login needed. Each vote ends with a cryptographic confirmation.
4. **Results** — Automatic charts, turnout statistics, PDF reports, and an integrity audit report.
5. **Archive** — Complete audit documentation and hash-verified records for long-term storage.

## Key Features

- **Admin dashboard** — manage all elections across their lifecycle: summary stats, live turnout, results, and archive
- **Election creation wizard** — basic info, candidates, voter list, settings, review & publish
- **Magic-link voting** — voters never create accounts; single-use, expiring links keep access secure
- **Anonymous ballots** — voter identity is structurally separated from cast votes
- **Verifiable integrity** — cryptographically verifiable records and audit reports for every election
- **Results & reports** — winner, vote distribution, turnout, quorum status, and exportable PDF reports
- **Built for everyone** — single- and multi-choice elections, polls, and surveys

## Tech Stack

Full-stack **Next.js (App Router)** application in **TypeScript**, with **PostgreSQL + Prisma**, **Tailwind CSS + shadcn/ui**, and internationalized UI via **next-intl** (Croatian MVP; English post-launch). Deployed on **Vercel**.

## Status

**MVP in development.** MVP locale: 🇭🇷 Croatian (`hr`) — English ships post-launch, i18n-ready from day one.
